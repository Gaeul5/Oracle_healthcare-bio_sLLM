## 1. 연구 질문

학습 데이터의 **표현 형식(representation format)** 이 소형 생성 언어모델의
**도메인 간 ADE(이상반응) 추출 일반화**에 영향을 주는가.
그리고 그 효과는 모델 크기가 작을수록 커지는가.

## 2. 가설

- **H1.** 인과 구조를 명시한 형식(R3/R4)으로 학습한 모델이,
  동일 교사·동일 원문의 자유서술 형식(R2)으로 학습한 모델보다
  미학습 도메인에서 높은 ADE 추출 F1을 보인다.
- **H2.** H1의 효과 크기는 모델 파라미터 수가 작을수록 크다.

> H1·H2가 기각되어도 결과로 보고한다. 특히 "차이 없음"은
> **구조화의 이득 대부분이 교사 지식 전이였다**는 결론으로서 유효한 발견이다.

## 3. 선행 연구와의 관계

MultiADE (Dai et al., *J Biomed Inform* 160:104744, 2024)는
동일 코퍼스군에서 도메인 간 일반화를 **측정**하였다 (인코더 기반 span 모델 + BART 생성 모델).
본 연구는 동일 벤치마크 위에서 **개입(intervention)** 을 수행한다:
모델 구조가 아니라 **학습 데이터의 표현 형식**을 조작한다.

MultiADE가 보고한 ADE 추출 F1 (span-based, 참고용 기준선):

| 학습 → 평가 | F1 |
|---|---|
| PsyTAR → PsyTAR (in-domain) | 68.5 |
| CADEC → CADEC (in-domain) | 67.7 |
| PHEE → PHEE (in-domain) | 69.0 |
| CADEC → PsyTAR (포럼 내부) | 54.2 |
| CADEC → PHEE (포럼→문헌) | 22.5 |
| PsyTAR → PHEE (포럼→문헌) | 27.6 |
| **PHEE → PsyTAR (문헌→포럼)** | **6.5** |
| **PHEE → CADEC (문헌→포럼)** | **13.1** |

→ **비대칭이 존재한다.** 포럼→문헌보다 문헌→포럼이 훨씬 어렵다.
본 연구는 이 비대칭이 표현 형식에 의해 완화되는지를 검증한다.

## 4. 주 평가 지표

- 미학습 도메인에 대한 **ADE 멘션 추출 F1** (완화 매칭 및 엄격 매칭 병행 보고)

## 5. 부 평가 지표

- Risk–Coverage curve, Coverage at fixed risk (**주 안전성 지표**)
- ECE, Brier score (보조 — 리뷰어 관례상 병기)
- 일반 능력 보존율 (특화 학습으로 인한 망각 측정)
- 4bit 양자화 후 성능 유지율, 초당 토큰 수, 최대 메모리 (**sLLM 자격 요건**)

## 6. 실험 조건 (표현 형식)

| ID | 형식 |
|---|---|
| R0 | 원문 그대로 |
| R1 | 용어만 정규화 |
| **R2** | **교사 모델의 자유서술 — 교사 지식 통제군** |
| R3 | 구조화 필드 |
| R4 | 구조화 + 판단 근거 한 줄 |

**통제 조건 (절대 위반 금지):**
- 교사 모델 동일, 원문 동일, 생성 파라미터 동일
- 조건 간 출력 토큰 수 ±20% 이내로 정렬
- 교사는 오픈웨이트 모델 사용 (상용 API 출력으로 학습 금지)

## 7. 데이터

| 코퍼스 | 도메인 | 문서 | 라이선스 |
|---|---|---|---|
| CADECv2 (csiro:62387) | forum | 3,526 | CC BY |
| CADEC v1 (DOI 10.4225/08/570FB102BDAD2) | forum | 1,155 | CSIRO Data Licence |
| PsyTAR | forum | 835 | CC BY 4.0 |

- n2c2 / MADE 1.0: **제외.** n2c2는 팀 리더가 교수진이어야 하며 학생 단독 팀은
  승인되지 않고, MADE는 IRB 승인서를 요구한다. 본 연구 조건에서 접근 불가.
- SMM4H: **제외.** 트윗 ID만 배포되어 재현이 보장되지 않는다 (MultiADE와 동일한 사유).

## 8. 엔티티 매핑

MultiADE Table 4의 행 #2를 그대로 따른다:

```
PHEE 'Effect'  =  PsyTAR 'ADR'  =  CADEC/CADECv2 'ADE'
```

**PHEE의 'Adverse_event'는 사용하지 않는다.** 이는 사건 트리거(예: "developed")로,
다른 코퍼스의 ADE 정의와 다르며 MultiADE에서도 별도 카테고리(#15)로 분리되어 있다.

## 9. 데이터 분할

**주 축 — 도메인 이전 (양방향)**
```
forum (CADECv2 + CADEC v1 + PsyTAR)  →  literature (PHEE)
literature (PHEE)                    →  forum
```

**보조 축 — 포럼 내부 약물 그룹 교차검증** (6그룹)
`ANTIDEPRESSANT / ACID_RELATED / STATIN / ANTIDEPRESSANT_PSY / ANTIHYPERTENSIVE / NSAID`

- 보정셋은 학습·평가와 그룹이 겹치지 않도록 별도 폴드로 배정한다.
- 폴드 배정 결과는 `data/fold_assignment.csv`에 고정하며 이후 변경하지 않는다.

## 10. 전처리 결정

- **불연속 엔티티: 최소 포함 구간으로 병합 (B안).**
  근거: CADECv2 ADR 23,538개 중 불연속 2,530개(10.7%). 병합 시 추가되는
  문자 수 중앙값 9자, 병합으로 서로 겹쳐 소실되는 엔티티 23개(전체의 0.10%).
  생성 모델이 원문에 없는 문자열을 출력하지 않도록 하기 위함.
  부록에서 "병합하지 않음" 조건을 비교 실험으로 보고한다.
- **PsyTAR 문서 텍스트**는 `Sentence_Labeling` 시트의 문장을 순서대로 이어붙여
  복원한다. `Sample.comment`만 사용하면 ADR 주석의 약 80%가 원문에서 매칭되지 않는다
  (주석이 `side-effect` 필드 + `comment` 필드 합본에 정렬되어 있기 때문).
- **문서 단위**: 게시글/초록 단위. MultiADE는 PsyTAR를 문장 단위(3,147)로 사용했으나,
  본 연구는 서사에 걸친 인과 구조를 다루므로 리뷰 단위를 유지한다. 논문에 명시한다.
- **중복 제거**: 본문 정규화 기준 전역 중복 제거 (CADEC v1 ↔ CADECv2 간 실측 중복 존재).

## 11. 보정 방법

**temperature scaling으로 사전 확정한다.** 데이터 규모와 재현성을 고려한 선택이며,
다른 보정 방법과의 비교 실험은 수행하지 않는다.

## 12. 성공/실패 판정

- R2와 R3의 차이가 **어느 방향으로든** 측정되면 성공으로 간주한다.
- 폴드·방향별 승패 수(예: 4개 중 3개)로 일관성을 보고한다.
- 방향성이 없으면 "차이 없음"을 결론으로 보고한다.

## 13. 수행하지 않는 것

DPO / Long Context / verifier·latent reasoning / 대형 지식그래프 /
다중 샘플링(test-time scaling) / 멀티에이전트 / 장기 메모리

## 14. 계획 변경 허용 조건 (아래 3가지에 한함)

1. 학습이 수렴하지 않아 수치 산출이 불가능한 경우
2. 데이터 확보 실패로 평가셋이 200건 미만인 경우
3. 폴드·방향 간 편차로 인해 어떤 조건 비교도 불가능한 경우

> "결과가 아쉽다", "더 좋아 보이고 싶다", "시간이 남는다"는 변경 사유가 아니다.
